## Source Code & How to run
- โค้ดทั้งหมดอยู่ในโฟลเดอร์ `src/`
- **วิธีรันโปรแกรม:**
  1. เปิดเซิร์ฟเวอร์: `python src/server.py`
  2. เปิดผู้รับข้อมูล: `python src/subscriber.py`
  3. เปิดผู้ส่งข้อมูล: `python src/publisher.py`
